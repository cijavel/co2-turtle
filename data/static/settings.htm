Sensor Intervals

One-Shot Calibration

Procedure:
  1. Place the device near an open window or outside.
  2. Wait at least 20 minutes for the reading to stabilise close to ~400 ppm.
  3. Press the button below — the current value is stored as the 400 ppm zero point.
Effect is immediate. Works on all MH-Z19 variants. Use this if a sensor is stuck at very high values (e.g. 10000 ppm).

24h ABC Session

Enables ABC for exactly 24 hours, then automatically reverts to your persistent ABC setting above. Useful for one-time recovery without permanently changing ABC. Only available on MH-Z19B / MH-Z19C.

This feature is only available on MH-Z19B / MH-Z19C. The detected variant on this device does not support ABC.
While the session runs:
  • Open a window once or twice during the 24 h so the sensor sees fresh air (~400 ppm).
  • The lowest CO2 reading reached during the window is shown below in real time.
  • If the minimum stays well above ~420 ppm, ABC will not have recalibrated correctly — use the One-Shot Calibration above instead.
  • If the device is rebooted, the session is reset.
